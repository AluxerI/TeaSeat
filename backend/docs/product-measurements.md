# Product measurement API

Backend хранит количество товара в его базовой складской единице:

- `piece` — целые штуки;
- `gram` — целые граммы.

Карточка товара и строки корзины/заказа возвращают:

```json
{
  "price": 250,
  "stock_unit": "gram",
  "sale_step": 10,
  "price_unit_quantity": 100,
  "quantity": 110
}
```

Значение `price` — цена за `price_unit_quantity`. В примере это 250 рублей за 100 граммов.

Frontend может менять `quantity` с шагом `sale_step`, но не должен сам фиксировать итоговую цену. Предварительную сумму можно показать по формуле:

```text
price × quantity / price_unit_quantity
```

Для примера выше: `250 × 110 / 100 = 275 ₽`. Авторитетный расчёт всегда возвращают `POST /api/cart/quote` и checkout.

## Корзина

`POST /api/cart/add` и `PUT /api/cart/update/{itemId}` принимают целое `quantity`.

Backend проверяет:

```text
quantity >= sale_step
quantity % sale_step == 0
```

Некратное количество возвращает `422`. Значение `0` допустимо только при обновлении позиции и означает её удаление.

## Скидки

Для `piece` товарная скидка и её лимит расходуются по числу штук. Для `gram` скидка и одно использование лимита применяются один раз ко всей строке товара.
