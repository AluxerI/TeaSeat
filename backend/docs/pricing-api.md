# Pricing API

Расчёт цены выполняет backend. Frontend передаёт только выбранный вариант скидки
и никогда не отправляет рассчитанные суммы.

## Правила

1. Backend выбирает одну автоматическую акцию с максимальной экономией для каждой позиции.
2. После акций клиент может выбрать либо одну персональную скидку, либо один промокод.
3. `min_order_amount` выбранной скидки проверяется по сумме товаров после акций.
4. Процентные скидки применяются последовательно, а не складываются.
5. Для штучного товара фиксированная товарная скидка и её лимит считаются
   по количеству штук. Для развесного товара скидка применяется один раз ко всей строке,
   независимо от веса. Скидка на корзину или доставку также применяется один раз.
6. Окончательный расчёт и расход лимитов выполняются повторно в транзакции checkout.

Количество и цена развесных товаров описаны в [product-measurements.md](product-measurements.md).

## Предварительный расчёт

`POST /api/cart/quote`

Заголовок авторизации Sanctum обязателен.

Без выбранной скидки:

```json
{}
```

С персональной скидкой:

```json
{
  "discount_selection": {
    "type": "personal",
    "discount_id": 17
  }
}
```

С промокодом на корзину или доставку:

```json
{
  "shipping_address_id": 4,
  "delivery_method_id": 2,
  "discount_selection": {
    "type": "coupon",
    "code": "CART100"
  }
}
```

Для расчёта только выбранной части корзины передаются идентификаторы обычных
строк и подарков. Подарок выбирается целиком вместе со всеми компонентами:

```json
{
  "cart_item_ids": [12, 15],
  "cart_gift_ids": [4]
}
```

Если оба поля отсутствуют, рассчитывается вся корзина. Если хотя бы одно поле
передано, включается явный выбор, и суммарно должна быть выбрана минимум одна
позиция.

Для расчёта скидки на доставку поля `shipping_address_id` и
`delivery_method_id` обязательны. Ответ содержит базовую сумму, скидки по видам,
стоимость доставки, итог и разбивку по позициям:

```json
{
  "data": {
    "currency": "RUB",
    "products_total": 1000,
    "promotion_discount": 100,
    "personal_discount": 0,
    "cart_discount": 100,
    "shipping_cost": 200,
    "shipping_discount": 0,
    "final_total": 1000,
    "selected_discount": {
      "id": 21,
      "name": "Минус 100 рублей",
      "type": "cart",
      "value_type": "fixed",
      "value": 100,
      "code": "CART100"
    },
    "lines": []
  }
}
```

`422` означает, что скидка не существует, не принадлежит пользователю, истекла,
не подходит товарам, не проходит минимальную сумму или исчерпала лимит.

## Checkout

`POST /api/checkout`

Передаётся тот же объект `discount_selection`. Обязателен уникальный заголовок
`Idempotency-Key` длиной 8–128 символов. Повтор запроса с тем же ключом возвращает
ранее созданный заказ и не расходует скидку или остатки повторно.

```json
{
  "shipping_address_id": 4,
  "delivery_method_id": 2,
  "payment_method": "card",
  "cart_item_ids": [12, 15],
  "cart_gift_ids": [4],
  "discount_selection": {
    "type": "coupon",
    "code": "CART100"
  }
}
```

Цена из ответа `quote` является предварительной: checkout пересчитывает её по
актуальным ценам, датам действия и оставшимся лимитам.

После выборочного checkout невыбранные строки остаются в активной корзине.
Повторный `Idempotency-Key` допустим только с тем же набором идентификаторов;
другой состав возвращает `422`.
