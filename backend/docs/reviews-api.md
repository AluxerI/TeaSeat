# Отзывы о товарах и оценки заказов

API разделяет два независимых вида обратной связи.

- `review` оценивает конкретный товар и участвует в рейтинге товара;
- `order_feedback` оценивает доставку, сборку и сервис и никогда не влияет на
  рейтинг товара.

Полная машинно-читаемая схема находится в `docs/openapi/reviews-api.yaml`.

## Право на создание

Отзыв о товаре можно создать только по `order_product_id` из собственного
интернет-заказа со статусом `delivered` или `completed`. Для одного пользователя
допускается один отзыв на товар. `verified_purchase=true` выставляет сервер.

Оценка заказа создаётся один раз для собственного корневого интернет-заказа со
статусом `delivered` или `completed`. Нужно передать хотя бы одну оценку:
`delivery_rating`, `packing_rating` или `service_rating`.

Покупатель может исправлять только собственные записи. Редактирование скрытой
записи не публикует её автоматически.

## Клиентские маршруты

| Метод | URI | Назначение |
|---|---|---|
| `GET` | `/api/products/{product}/reviews` | публичные отзывы и рейтинг товара |
| `GET` | `/api/reviews/mine` | собственные отзывы, включая скрытые |
| `POST` | `/api/products/{product}/reviews` | создать отзыв о купленном товаре |
| `PUT` | `/api/reviews/{review}` | изменить собственный отзыв |
| `GET` | `/api/orders/{order}/feedback` | собственная оценка заказа |
| `POST` | `/api/orders/{order}/feedback` | создать оценку заказа |
| `PUT` | `/api/order-feedback/{feedback}` | изменить собственную оценку заказа |

Все маршруты, кроме публичного списка, требуют Sanctum-токен.

Пример создания отзыва:

```json
{
  "order_product_id": 184,
  "rating": 5,
  "comment": "Чай понравился"
}
```

Пример оценки заказа:

```json
{
  "delivery_rating": 5,
  "packing_rating": 4,
  "service_rating": 5,
  "comment": "Доставили вовремя"
}
```

## Модерация менеджером

Менеджер и администратор с правами `view reviews` и `moderate reviews` могут:

- просматривать отзывы и оценки;
- скрывать запись только с кодом нарушения и комментарием;
- восстанавливать запись с комментарием;
- создать или изменить единственный официальный ответ компании под отзывом о
  товаре.

Они не могут изменить оценку или текст покупателя и не могут удалить запись.
Каждое скрытие и восстановление записывается в `content_moderation_logs` со
снимком имени сотрудника. Повтор одной и той же команды идемпотентен и не создаёт
дублирующую запись журнала.

Коды нарушений: `spam`, `abuse`, `personal_data`, `off_topic`, `fraud`, `other`.

| Метод | URI |
|---|---|
| `GET` | `/api/manager/reviews` |
| `GET` | `/api/manager/reviews/{review}` |
| `POST` | `/api/manager/reviews/{review}/hide` |
| `POST` | `/api/manager/reviews/{review}/restore` |
| `PUT` | `/api/manager/reviews/{review}/reply` |
| `GET` | `/api/manager/order-feedback` |
| `GET` | `/api/manager/order-feedback/{feedback}` |
| `POST` | `/api/manager/order-feedback/{feedback}/hide` |
| `POST` | `/api/manager/order-feedback/{feedback}/restore` |

`GET /api/manager/order-feedback` дополнительно возвращает независимые средние
оценки и количество голосов по категориям `delivery`, `packing`, `service`.

## Ошибки

- `401` — отсутствует токен;
- `403` — недостаточно прав менеджера;
- `404` — запись не существует или не принадлежит покупателю;
- `409` — покупка ещё не завершена либо отзыв уже существует;
- `422` — ошибка формата или обязательных полей.
